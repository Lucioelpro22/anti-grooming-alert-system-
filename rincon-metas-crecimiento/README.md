# 🌱 Mi Rincón de Metas y Crecimiento

**Proyecto Nº 3 de 6 — Serie original**

PWA local-first para metas diarias/semanales, progreso visual, logros personales, acuerdos de celebración y reflexiones.

Principios: sin rankings, sin rachas obligatorias, sin castigo por pausar o reajustar una meta, sin publicidad ni telemetría.

~~~bash
cd rincon-metas-crecimiento
pip install -r requirements.txt
uvicorn api.main:app --reload --port 8007
~~~
