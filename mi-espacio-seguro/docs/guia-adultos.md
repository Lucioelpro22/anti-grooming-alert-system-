# Guía para personas adultas

Si un niño/a usa este espacio para contar una situación:
- escuchar antes de interrogar;
- evitar culpar o retar por haber respondido, compartido o confiado;
- priorizar seguridad física y emocional;
- preservar información útil sin redistribuir contenido íntimo;
- usar canales oficiales/profesionales adecuados cuando la situación lo requiera.

La app no realiza denuncias automáticas ni sustituye protocolos institucionales.
